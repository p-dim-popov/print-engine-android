# print-engine-android

A command-line printing tool over [Gutenprint](https://gimp-print.sourceforge.io/): PWG Raster pages in, a printer's own bytes out. It builds for Linux and for Android (NDK), where an app can run it as a separate program for one print job.

Work in progress. The interface (`describe` and `print`), the build and the tests arrive in the first pull requests.
